# 字幕节奏修复（SRT Rhythm Fix）

在浏览器内修复 SRT 字幕的**断句**与**毫秒时间边界**：保持文字内容与顺序不变、保持选区首条开始时间与末条结束时间不变，在「每秒字符数 / 单行字数 / 最小提示间隔」三组限制下，求**边界总移动量最小**的可行方案；无解时逐条列出冲突规则。所有数据仅保存在浏览器本地，不上传任何服务器。

技术栈：**React 18 + TypeScript + Vite**，纯前端、无后端。

## 一键启动

### 方式一：Docker Compose（推荐，生产构建）

```bash
docker compose up --build -d
```

然后打开：

- **地址**：http://localhost:**8080**
- 端口可改：`PORT=9000 docker compose up --build -d`

停止：`docker compose down`

### 方式二：Docker Compose（开发模式，带热更新）

```bash
docker compose -f docker-compose.dev.yml up
```

然后打开：

- **地址**：http://localhost:**5173**（Vite dev server）
- 端口可改：`DEV_PORT=3000 docker compose -f docker-compose.dev.yml up`

### 方式三：本地 Node（需 Node.js 20+）

```bash
npm install
npm run dev        # 开发：http://localhost:5173
npm run build && npm run preview   # 生产预览：http://localhost:4173
```

## 使用步骤

1. **导入 SRT**：选择本地 `.srt` 文件（兼容 BOM / CRLF / 逗号或点毫秒），或点击「载入示例」。
2. **选取字幕**：在列表中点击，选择**至多 30 条连续字幕**（再次点击端部条目可收缩选区）。
3. **设置参数**：
   - **每秒字符数（CPS）**：每条字幕时长 ≥ `1000 × 字数 ÷ CPS`（节奏下限，默认 17）；
   - **单行字数**：词感知折行后的每行最大字符数（中日韩文字可逐字断行，拉丁词不拆词，默认 18）；
   - **最小提示间隔**：相邻两条字幕之间的最小间隔毫秒数（默认 120ms）；
   - 每条字幕固定最多 2 行（标准字幕规范）。
4. **求解与比对**：点击「求最小移动方案」，左右并排展示**原稿**与**结果**——
   - 黄色底纹：跨条移动的文字；
   - 蓝色标签：该开始/结束边界移动的毫秒数；
   - 顶部汇总：时间边界总移动量、文字移动量、移动字符数。
5. **确认导出**：点击「确认并导出 fixed.srt」下载完整 SRT（选区替换为修复结果、选区外原样保留、序号重排）。

若约束下无解，页面会列出**每一条冲突规则**及数值依据，按提示放宽对应参数即可。

## 求解原理（摘要）

- **时间优化（精确全局最优）**：给定断句后，所有边界约束可变换为一条非减变量链，目标 `Σ|新边界 − 原边界|` 是标准 **L1 保序回归（Isotonic Regression）**，用 **PAVA（Pool Adjacent Violators）+ 加权中位数**精确求解；选区首/末边界用极大权重钉死。
- **断句优化（该时间方案下精确最优）**：在分层 DAG 上做密集数组 DP，词典序最小化 `(时长缺口, 文字移动量)`，段合法性（非空、2 行折行、行长）带缓存。
- **联合优化（非凸组合问题）**：以 3 组结构化切点（均匀 / 按原字数 / 按原时长）+ 上百组随机合法切点为起点交替迭代到不动点，再做模拟退火（单/双切点扰动）与确定性双邻域精修（单/双切点 ±3 直接评估原始时间目标），取其中移动量最小的方案。两个子问题均为精确解，联合层为高质量启发式（固定随机种子、结果可复现；30 条规模约 3 秒）。
- **验证**：`npm test` 包含 780+ 项断言，其中时间优化器在 60 个随机案例上与整数坐标暴力 DP 完全一致；小规模（≤4 条）联合求解与“枚举全部断句 × 每案最优时间”的全局最优逐一对照。

## 配置一览

| 配置 | 默认值 | 位置 / 方式 |
| --- | --- | --- |
| 生产端口 | `8080` | `docker compose` 环境变量 `PORT` |
| 开发端口 | `5173` | `docker-compose.dev.yml` 环境变量 `DEV_PORT`，或 `vite.config.ts` |
| CPS 上限 | 17 | 页面参数区 |
| 单行字数 | 18 | 页面参数区 |
| 最小间隔 | 120 ms | 页面参数区 |
| 选区条数上限 | 30 | 页面逻辑（`MAX_SELECTION`） |
| 每屏行数上限 | 2 | 求解器常量（`MAX_LINES`） |

参数会随浏览器 `localStorage` 记住；导入的 SRT 原文同样仅存于 `localStorage`，可在页面上「清空」。
